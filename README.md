# Our Springfield v0.8

A private, original cartoon-town-builder prototype designed for landscape iPhone play.

## v0.8 visual polish
- Reworked the town ground into bright green suburban lots with diagonal paved roads and pale sidewalks.
- Added hand-drawn-style trees, shrubs, flowers, and stronger outlines.
- Replaced simple emoji building markers with cartoon isometric houses featuring colored walls, roofs, chimneys, windows, and doors.
- Added small stylized yellow residents on the map.
- Updated the service-worker cache name so the new version refreshes on iPhone.

## Install
Extract this ZIP and upload the files inside `our_springfield_v3` to the existing GitHub Pages repository, replacing the previous files. Keep the same repository and Pages URL. After the deployment completes, close and reopen the installed web app or refresh Safari.

## Current prototype limitations
This remains a front-end prototype. Progress is saved locally on the device. Online accounts, cloud saves, friend visits, and a complete story quest system are not implemented yet. The art and characters are original Simpsons-inspired cartoon designs, not copied show or game assets.
