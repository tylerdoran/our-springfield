# Our Springfield v0.9

This update refines the town's cartoon presentation with more expressive original residents, including oversized eyes, yellow skin tones, varied hair silhouettes, outlined clothing, legs, shoes, and facial expressions. It keeps the existing landscape layout, town save data, building placement, building income, character tasks, and task-book interface.

## Update
Upload the files in this folder to the existing GitHub Pages repository, replacing the previous versions. Keep the same repository and Pages URL. If the iPhone shows the old version, close the installed web app and reopen it after the new deployment succeeds.

Artwork and characters are original genre-inspired creations, not extracted game or television assets.
