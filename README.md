# Our Springfield v0.7

A private, original isometric town-building web game prototype. It uses original placeholder artwork and characters while building toward a classic mobile town-builder interface.

## What's new in v0.7
- Reworked the landscape HUD to keep the town visible behind the controls.
- Added a vertical character shortcut rail. Busy characters show an hourglass; completed tasks show a ready marker. Tap a character to open the resident task menu.
- Added a task-book button at the lower left. It opens an overlay with active objectives and progress.
- Added the three-button action dock at the lower right for Build, Residents, and town management/income.
- Moved the level and XP display and unlimited currency indicators into on-screen HUD overlays.
- Updated the service-worker cache version so iPhone Safari can fetch the new files.

## Install/update
1. Extract this ZIP on your computer.
2. Upload the files inside this folder to the existing GitHub Pages repository, replacing the old files.
3. Wait for the latest GitHub Actions workflow to finish successfully.
4. Close the game on the iPhone and reopen the same GitHub Pages URL. If the previous version remains visible, refresh Safari.

## Important limitations
This is still a front-end prototype. It stores town data locally on each device. Online accounts, cloud saves, friend invitations, and visiting other towns are not implemented. The character roster, quests, buildings, artwork, and map are original placeholders, not EA game assets. The interface and high-level gameplay are inspired by classic isometric town-building games; it is not an exact copy of The Simpsons: Tapped Out.
