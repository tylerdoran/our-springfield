OUR SPRINGFIELD — UPDATE 40

This build keeps the Update 39 game code and saved-game storage, updates the page title, and adds a small "Update 40" label at the top right to confirm which build is actually loading.

IMPORTANT: GitHub Pages publishes the ROOT index.html. Uploading this ZIP or its extracted folder as another subfolder will NOT replace the live game.

EASIEST DEPLOYMENT:
1. Extract this ZIP on your PC.
2. Open https://github.com/tylerdoran/our-springfield (repository root).
3. Choose Add file > Upload files.
4. Drag ONLY the extracted index.html (not the enclosing folder or ZIP).
5. Commit changes, then check Actions/Pages for successful deployment.
6. Open https://tylerdoran.github.io/our-springfield/?build=40 in Safari.

If the top-right label is not Update 40, the root file has not been deployed or an old cached page is loading. Do not clear site data unless your saved town is backed up; this game uses browser storage.
